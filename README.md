# CSV Data Dashboard

A simple interactive data dashboard built using Streamlit and Python.

[Launch App on Streamlit community cloud](https://csvdatadashboard-fvsw8kxecsvyejexnzyh3t.streamlit.app/ )

## Overview

This application allows users to upload a CSV file and explore the data through an interactive dashboard.

Users can:
- Upload CSV datasets
- View data tables
- Generate summary statistics
- Visualize numeric columns using charts

The project demonstrates how quickly data applications can be built using Streamlit.

## Features

- Upload CSV files
- Display dataset preview
- Generate statistical summary
- Automatic charts for numerical data
- Simple and interactive UI

## Technologies Used

- Python
- Streamlit
- Pandas
